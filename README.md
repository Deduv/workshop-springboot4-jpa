## Sobre o projeto

API REST desenvolvida com Spring Boot 4 e JPA/Hibernate, com modelo de domínio envolvendo usuários, pedidos, produtos, categorias e pagamentos. O projeto abrange CRUD completo, arquitetura em camadas e tratamento de exceções.
